# Contributors Wall

Every file in this folder becomes a card on the `/contributors` page.

To add yourself:

1. Copy `_template.json` to a new file named after your GitHub username, e.g. `octocat.json`.
2. Fill in your details. Only `name` and `github` are required.
3. Open a pull request. Because everyone edits a different file, there are no merge conflicts.

Files starting with `_` are ignored.
